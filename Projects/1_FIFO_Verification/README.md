# FIFO Verification

## Description

Implemented a parameterized synchronous FIFO in SystemVerilog.

## Features

- Parameterized DATA_WIDTH and DEPTH
- Write operation
- Read operation
- Full flag
- Empty flag
- Simple SystemVerilog testbench
